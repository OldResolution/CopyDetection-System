# 📚 Classic Literature Dataset (Books)

Welcome to the **Books Dataset** for the CopyDetection-System! This directory houses a curated collection of **94 classic literature titles** in `.epub` format. 

These books serve as the primary text corpus for testing, training, and running the copy detection and plagiarism analysis algorithms.

## 📁 Format & Content

- **Format:** All files are provided in `.epub` (Electronic Publication) format.
- **Total Files:** 94 books.
- **Content Type:** Classic literature and fiction (public domain).

## 🛠️ Usage in CopyDetection-System

These text files provide a robust, extensive, and linguistically diverse set of documents. They are used to benchmark the system's ability to detect plagiarism, direct copying, and complex paraphrasing. Since these are well-known texts, they provide a highly reliable baseline for natural language processing (NLP) tasks and algorithm evaluation.
